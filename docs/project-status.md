## 阶段结论

- 2026-08-07 已完成国际化 PR-A 基础设施的第一部分：统一 `zh_CN`/`ko_KR` 白名单、请求级
  Locale 解析、用户 `preferred_locale` 增量字段、匿名 Session/加密 Cookie 持久化、登录同步、
  语言设置 POST 页面和基础语言文件。随后已完成 PR-B 日常页面及 PR-C 第一批配置中心、内部用户、
  结算、提醒、多维查询和导入页面的中韩文案、状态映射、动态标题与韩文 Feature 覆盖；导出文件名、
  队列/通知任务、深层异常码和动态业务错误正文仍待后续 PR，韩文入口暂不加入业务导航。

- Phase 2 的代码交付已结束：核心数据模型、导入契约、加密上传、解析校验、事务
  预演、人工裁决、原子提交、回滚、清理和模拟数据均已实现并通过自动化验证。
- 2026-08-06 已补强历史导入正确性：XLSX 日期单元格保留原始元数据，代理商引用统一
  写入规范编号，月结汇总按代理商和结算周期核对；旧模板会复用结算日期推导的周期，合法
  全零月结允许无当月明细，非零无明细、当月明细全部无效、汇总差异和跨字段或规范化名称
  歧义仍会阻止导入。
- Phase 3 已完成客户建档、档案编辑、列表筛选、详情聚合、跟进登记、状态流转、
  生命周期时间轴、状态配置、敏感字段脱敏和操作审计。
- Phase 4 已完成代理商档案、类型代码、政策等级、机构费率、代理商特批、最小订单
  完成流程、推广费核算快照和相关审计。
- Phase 5 已完成版本化月结、按历史合作期间选取代理商、真实周期边界重建、按代理商异步批次、
  零订单生成、审核结清、结算文档、等级建议、主动提醒规则与生命周期、站内任务和可选钉钉通知。
- Phase 6 已完成 9 维 AND 查询、私有 Excel 导出、真实数据看板及 PDF/HTML 导出，
  并补齐机构/定向字典/直销来源/用户管理、配置分类快照与回滚。
- Phase 5/6 与订单中心已通过 PHP 测试、Pint、PHPStan、容器前端构建、生产镜像和
  UAT/Production Compose 门禁；真实规模性能和人工业务流程仍须在 UAT 验收。
- `v0.5.0-rc.8` 已在绿色 CI 后合入 `main`，包含最近一个 RC 发布与运维文档基线；当前 `main` 已
  提交结算工作流和前端易用性优化，覆盖历史参与范围、周期边界重建、月结生成状态持久化、
  零订单审核、批次启动结果和汇率失败反馈；新增迁移会回填既有月结并将无法确认的记录标记为
  `unverified`；超级管理员可通过受审计的历史核验或恢复批次处理无旧批次记录，`not_applicable`
  明确保持只读。相关 Feature 断言已同步，但既有数据升级后的审计和 UAT 仍是上线前置条件，
  不得据此宣称 UAT 或生产已验证。
- 同机 UAT 已在 `/srv/gn-system` 正常运行；Production 已在
  `/srv/gn-system/production` 初始化目录，但尚未首次部署。两者不共享数据。
- 真实历史文件全量迁移、错误处理和抽样核对是独立的上线验收工作；完成前不得宣称
  “生产历史数据迁移完成”，但不再阻塞 Phase 2 开发收尾。
