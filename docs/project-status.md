## 阶段结论

- Phase 2 的代码交付已结束：核心数据模型、导入契约、加密上传、解析校验、事务
  预演、人工裁决、原子提交、回滚、清理和模拟数据均已实现并通过自动化验证。
- Phase 3 已完成客户建档、档案编辑、列表筛选、详情聚合、跟进登记、状态流转、
  生命周期时间轴、状态配置、敏感字段脱敏和操作审计。
- Phase 4 已完成代理商档案、类型代码、政策等级、机构费率、代理商特批、最小订单
  完成流程、推广费核算快照和相关审计。
- Phase 5 已完成版本化月结、按代理商异步批次、审核结清、结算文档、等级建议、
  主动提醒规则与生命周期、站内任务和可选钉钉通知。
- 真实历史文件全量迁移、错误处理和抽样核对是独立的上线验收工作；完成前不得宣称
  “生产历史数据迁移完成”，但不再阻塞 Phase 2 开发收尾。

## 部分实现

以下模块仍未形成完整日常业务能力：

- Report
- Config（已提供统一配置入口及 Phase 2 引用能力，完整系统字典维护尚未实现）
- Audit

Report 仍只有模块骨架。模块目录或数据表存在不代表对应完整 CRM 流程已经实现。

## 尚未实现

- Order、Settlement 的完整 CRUD 和日常业务流程
- 机构、直销来源和其他系统字典的完整配置中心
- 领域事件或现有同步 Application 契约之外的跨模块协作机制
- CQRS、看板预聚合表和业务查询缓存
- 钉钉真实机器人凭据配置和生产实发验收
- 目标服务器、内网 DNS/可信证书、主机防火墙、UPS、NAS 挂载及首次恢复演练
- 双机高可用、对象存储、PostgreSQL 主从和 WAL/PITR
