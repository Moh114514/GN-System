# Phase 4 代理商与推广费核算

## 交付范围

Phase 4 提供代理商列表、建档、编辑、详情，代理商类型、政策体系、等级、机构费率
和代理商特批配置，以及从客户详情进入的最小订单登记与完成流程。合同附件、独立
订单中心、订单取消/删除、月结审核和结算单不在本阶段。

代理商与配置页面只允许已启用 2FA 的超级管理员访问。普通内部用户可使用客户订单
入口，但不能进入代理商档案和配置中心。

## 数据所有权与协作

- Agent 拥有类型代码、代理商、政策体系、等级和等级生效历史。
- Order 拥有订单状态和完成日期。
- Settlement 拥有等级机构费率、代理商特批和订单推广费快照。
- Customer 与 Config 分别通过只读 Contract 提供客户、直销来源和机构引用。
- Order 完成代理商订单时，在同一事务中通过 Settlement Contract 核算；Settlement
  再通过 Agent Contract 读取当月有效政策等级。

具体事务和失败语义见
[ADR-0006](../adr/0006-synchronous-order-commission-contract.md)。

## 固化业务规则

- 代理商编号为 `简称-类型代码`，类型代码是 2–4 位大写字母数字；编号建档后永久
  不变，修改代理商类型也不改编号。
- 系统类型 `JG`、`GT`、`KR` 不可改代码，所有类型、政策和等级只停用不物理删除。
- 新代理商初始等级当月生效；后续等级变化从下月生效。费率和特批按月初生效，
  已开始月份的既有配置不可修改。
- 合作中代理商可产生新订单与推广费；暂停代理商不可产生新订单；已终止代理商
  永久只读。
- 费率优先级为机构特批、全机构特批、等级机构费率。不存在有效规则时订单完成
  失败，不使用默认值或静默降级。
- 直销订单不产生推广费。代理商订单按 KRW 整数金额乘基点费率计算并半入取整。
- 已完成订单每单只有一条推广费，快照不受未来配置调整影响。

## 当前限制

- 订单首期只有待完成和已完成两种状态；完整状态流转属于后续订单中心。
- 不实现累计阶梯、政策体系兜底费率、领域事件、缓存或历史推广费重算。
- 月业绩门槛仅作为等级配置数据保存，本阶段不自动生成升降级建议。
