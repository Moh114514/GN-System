# 订单中心

## 交付范围

订单中心是侧栏一级业务页面，面向全部已认证内部用户，提供全量订单查询、新建订单
和待完成订单的完成操作。客户详情中的订单入口继续保留，两处入口共用同一
Application 服务和事务规则。

当前列表支持按订单号、客户姓名/编号、项目名称、状态、渠道、机构和代理商筛选，
并支持 20/50/100 条分页。新建订单时先搜索并选择客户，再录入机构、渠道、
代理商或直销来源、项目、成交金额、完成时间、翻译和备注。

## 数据与事务规则

- Order 只写 `orders`；客户、代理商、机构和字典均通过数据所有者的 Application
  Contract 读取。
- 待完成订单进入已完成状态时，沿用既有同步事务：代理商订单固化推广费快照，
  所有订单建立术后提醒并写订单审计；任一环节失败则订单状态不变。
- 直销订单不产生推广费。
- 已完成订单及推广费快照在订单中心保持只读。
- 订单中心不静默修改客户原始来源；选定客户后只把原始来源作为新订单默认值，
  用户仍可按本次实际渠道调整。

## 当前限制

仓库当前只定义 `pending` 与 `completed` 两种订单状态。取消、退款、软删除及已完成
订单更正的审批/冲正语义尚未形成已接受业务规则，本次不新增猜测性状态或物理删除。
