# 订单中心

## 访问与状态编辑安全

- 普通内部用户只能查询未删除订单；订单中心通过独立的“回收站”二级页面提供已删除订单入口，服务端仅允许超级管理员读取和恢复。
- 订单详情页不再提供人工完成入口：待完成订单只能由机构固定表单回传流程生成已完成事实；超级管理员仍可以取消待完成订单，未删除的已取消订单可重新打开，并可填写原因将已完成订单受控回退为待完成。
- 订单生命周期迁移的 `down()` 在存在已取消、已删除或相关原因/操作人记录时会拒绝回滚，避免把业务事实静默改回待完成或丢失审计字段。

## 交付范围

订单中心是侧栏一级业务页面，面向全部已认证内部用户，提供全量订单查询和订单详情；
机构回传中心是独立的二级业务页面，负责下载版本化机构模板和上传原始回传文件。
客户详情中的订单入口继续保留，两处入口共用同一查询 Contract 和权限规则；普通人工新建、
人工完成入口已移除。

当前列表支持按订单号、客户姓名/编号、项目名称、状态、机构和代理商筛选，
并支持 20/50/100 条分页；状态包含待完成、已完成和已取消。超级管理员从订单中心
进入独立二级回收站页面查看回收站订单。机构回传中心先按机构和客户生成固定 XLSX 模板，
模板包含隐藏元数据、表单 UUID 和 HMAC 完整性签名；上传时校验客户、日期、项目、数量、
金额和重复文件。订单详情展示客户、机构、代理商、业务归属快照、财务快照、关联提醒和操作记录；
待完成订单仍可编辑允许编辑的业务字段，但不能通过页面手动完成。

## 数据与事务规则

- Order 只写 `orders`；客户、代理商、机构和字典均通过数据所有者的 Application
  Contract 读取。
- 机构回传成功在一个数据库事务中创建 `orders`、`order_items`、推广费快照、客户完成状态、
  术后 7/30 天提醒和审计；任一环节失败，订单、推广费、客户状态和提醒全部回滚，原始回传文件
  仍以失败状态保留在私有加密存储中。
- 订单事实使用 `occurred_on` 作为业务发生日期，使用 `record_status` 和业务归属快照保留
  可追溯语义；订单明细保存项目、规格、数量、单价和金额快照。
- 机构模板为版本化记录，隐藏元数据签名绑定机构、客户和表单 UUID；回传文件使用 SHA-256
  和表单 UUID 双重去重，原始文件只能通过客户业务范围或超级管理员授权下载。
- 已完成订单及推广费快照在订单中心默认只读；受控回退会清理未进入月结明细的推广费快照，并取消未执行的术后提醒。
- 待完成订单可以编辑；客户关联不可更换，编辑会记录前后字段差异。
- 仅超级管理员可以取消待完成订单、重新打开已取消订单、将已取消订单移入回收站以及恢复回收站订单；取消、重新打开和软删除均要求填写原因。
- 订单状态流转为 `pending → cancelled`、`cancelled → pending`、`completed → pending`（仅超级管理员、必填原因）；`pending → completed` 只由完整机构回传事务触发。已完成订单不允许取消、编辑或软删除；受控回退不等同于人工完成。
- 软删除只作用于已取消订单；恢复后仍保持已取消状态，不提供永久删除。
- 订单中心不静默修改客户归属；选定客户后把客户归属代理商作为新订单默认值，
  用户仍可按本次业务需要选择订单代理商。

## 当前限制

当前已实现待完成订单编辑、取消、软删除、回收站恢复、订单详情、版本化机构模板、
私有原始文件下载和机构回传原子入账；历史订单迁移仍要求先通过 pending/缺日期/缺代理商/
缺推广费快照/不可映射状态预检。退款、已完成订单更正/冲正、已结算订单反结算以及 Settlement
完整 CRUD 仍不在本阶段；UAT/Production migration、历史数据回填和人工业务验收尚未完成。
