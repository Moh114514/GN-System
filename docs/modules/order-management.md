# 订单中心

## 访问与状态编辑安全

- 普通内部用户只能查询未删除订单；订单中心通过独立的“回收站”二级页面提供已删除订单入口，服务端仅允许超级管理员读取和恢复。
- 订单详情页提供状态编辑入口：待完成可转为已完成，超级管理员还可以取消；未删除的已取消订单可由超级管理员重新打开。超级管理员填写原因后可以将已完成订单受控回退为待完成。
- 订单生命周期迁移的 `down()` 在存在已取消、已删除或相关原因/操作人记录时会拒绝回滚，避免把业务事实静默改回待完成或丢失审计字段。

## 交付范围

订单中心是侧栏一级业务页面，面向全部已认证内部用户，提供全量订单查询、新建订单、
订单详情和待完成订单的完成操作。订单详情是二级页面，待完成订单编辑是三级页面；
客户详情中的订单入口继续保留，两处入口共用同一 Application 服务和事务规则。

当前列表支持按订单号、客户姓名/编号、项目名称、状态、渠道、机构和代理商筛选，
并支持 20/50/100 条分页；状态包含待完成、已完成和已取消。超级管理员从订单中心
“新建订单”旁的“回收站”按钮进入独立二级页面查看回收站订单。新建订单时先搜索并选择客户，再录入机构、渠道、代理商或直销来源、项目、
成交金额、完成时间、翻译和备注。订单详情展示客户、机构、渠道、财务快照、关联提醒
和操作记录；待完成订单可编辑除客户、状态和完成时间之外的订单字段。

## 数据与事务规则

- Order 只写 `orders`；客户、代理商、机构和字典均通过数据所有者的 Application
  Contract 读取。
- 待完成订单进入已完成状态时，沿用既有同步事务：代理商订单固化推广费快照，
  所有订单建立术后提醒并写订单审计；任一环节失败则订单状态不变。
- 直销订单不产生推广费。
- 已完成订单及推广费快照在订单中心默认只读；受控回退会清理未进入月结明细的推广费快照，并取消未执行的术后提醒。
- 待完成订单可以编辑；客户关联不可更换，编辑会记录前后字段差异。
- 仅超级管理员可以取消待完成订单、重新打开已取消订单、将已取消订单移入回收站以及恢复回收站订单；取消、重新打开和软删除均要求填写原因。
- 订单状态流转为 `pending → completed`、`pending → cancelled`、`cancelled → pending`、`completed → pending`（仅超级管理员、必填原因）；已完成订单不允许取消、编辑或软删除。订单完成事务会为取消后再次完成的订单复活同一去重键下的未完成术后提醒，已完成提醒保持不变。
- 软删除只作用于已取消订单；恢复后仍保持已取消状态，不提供永久删除。
- 订单中心不静默修改客户原始来源；选定客户后只把原始来源作为新订单默认值，
  用户仍可按本次实际渠道调整。

## 当前限制

当前已实现待完成订单编辑、取消、软删除、回收站恢复和订单详情；退款、已完成订单
更正/冲正、已结算订单反结算以及 Settlement 完整 CRUD 仍不在本阶段。
