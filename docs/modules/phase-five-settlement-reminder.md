# Phase 5 月结、结算单与主动提醒

## 交付范围

Phase 5 提供版本化月结周期、自动和手动月结批次、进度与失败重试、财务审核、结清、
等级建议人工复核、Word/PDF/ZIP 结算单，以及面向内部员工的主动提醒中心、浅规则、
模板、生命周期日志和可配置钉钉通知。

完整订单 CRUD、多维查询、看板、复杂规则表达式和面向客户的消息发送不在本阶段。

## 月结规则

- 边界日限定每月 1–28 日，默认每月 1 日 09:00、`Asia/Shanghai`；配置从下一边界
  生效，正在处理的周期继续使用旧配置快照。
- 仅合作中代理商参与，按周期内已完成订单的推广费快照汇总。月结不会重新解析费率，
  缺少推广费或周期冲突会使对应代理商任务明确失败。
- 新月结状态为待审核、驳回、已通过和已结清；历史导入的已对账、已结清状态保留。
- 月结中心支持选择最近已关闭的往期周期生成月结；往期生成复用现有批次、代理商快照、审核、文档和结清流程，同一周期已有批次时保持幂等，不重复覆盖。往期节点按当时生效的周期配置计算。
- 审核使用正数 KRW/CNY 汇率计算人民币分值，Word 和 PDF 来自同一内容快照并保存于
  私有磁盘。
- 待审核或驳回月结详情会从接口盒子 KRW/CNY 报价服务预填六位小数汇率；该服务每日更新，
  报价来源、时间、可用状态和人工覆盖标记随月结保存。成功报价缓存十分钟，报价失败会明确提示，审核人仍可人工输入正数汇率。
- 仅超级管理员可在“待审核”“已审核”和“已结清”之间更正当前月结状态，且必须填写原因；回退到待审核会在同一事务中撤销结算明细、删除失效文档和等级建议、清空汇总金额，但保留此前采用的结算汇率，再以更正前后值、原因和 IP 记录审计。详情页会明确提示先重新生成月结明细，生成前禁止审核；汇率支持手动获取最新报价，报价失败时保留当前汇率。历史导入的 `paid`、`reconciled` 状态不允许更正。
- 等级建议以月推广费总额匹配同一政策体系门槛，只有超级管理员人工批准后才安排
  下月生效。

## 主动提醒规则

- 内置预约前 3 天、前一天、当天及术后 1/7/30/90/180 天提醒。
- 浅规则只支持状态变化、白名单日期字段偏移、固定周期和手动触发；适用范围一次只选
  全部客户、代理商、项目、负责人或合作状态之一。
- 提醒使用稳定去重键。改期重排未完成任务，预约取消关闭相关任务；模板修改不改写
  已生成实例。
- 普通内部用户只能查看分配给自己或自己创建的提醒；超级管理员可查看全部任务、
  完成率、规则与全局模板。
- 提醒只面向内部员工。钉钉未启用时站内提醒继续运行并显示未启用状态；发送失败记录
  日志并可由队列重试。

## 数据所有权

- Settlement 拥有月结配置、运行批次、结算单、结算明细、文档和等级建议。
- Reminder 拥有规则、模板、提醒实例与执行日志。
- Agent 拥有代理商资格、等级上下文与等级生效历史；Order 拥有订单和预约；Customer
  拥有提醒候选客户数据。跨模块协作只通过 Application Contract/Data。

事务与异步失败语义见
[ADR-0007](../adr/0007-phase-five-settlement-reminder-processing.md)。
