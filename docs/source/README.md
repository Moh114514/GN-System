- `CRM-需求文档-v1.9.md` 是当前业务需求上游。

- 文档中的“已确认”通常指需求或方案已确认，不代表代码状态。
- 当前实现请查阅[项目状态](../project-status.md)、[当前架构](../architecture/overview.md)、
  代码、迁移和测试。
